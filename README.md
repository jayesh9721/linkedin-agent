# LinkedIn Growth Agent

A React and Node.js dashboard matching the provided LinkedIn Growth Agent UI references.

## Run

```bash
npm install
npm run build
npm start
```

Open `http://localhost:3001`.

## Scripts

- `npm run build` builds the React app into `dist/`.
- `npm start` serves the React app and mock API from Express.
- `npm run client` starts the Vite dev server for frontend-only work.
- `npm run server` starts the Express API/static server.
